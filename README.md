# Proyecto de Automatización (Playwright + Java)

Proyecto personal para demostrar habilidades prácticas de automatización en **Web** y **APIs** usando Playwright con Java.

## 🎯 ¿Qué valida este proyecto?
- **Web (Saucedemo):** Flujo E2E de compra (login, agregar al carrito, checkout, cierre de sesión).
- **APIs:** Pruebas de contratos básicos sobre servicios de muestra (validación de status, esquemas de respuesta).

## 🛠️ Tecnologías
- Java 11
- Maven
- Playwright
- JUnit 5

## ▶️ Cómo ejecutarlo (en 3 pasos)
1. Clonar: `git clone https://github.com/RaulIsunza666/ProyectoPlayWright.git`
2. Entrar: `cd ProyectoPlayWright`
3. Ejecutar: `mvn clean test`

## 📁 Organización
- `src/test/java/Saucedemo/` → Pruebas E2E Web
- `src/test/java/Apis/` → Pruebas de servicios

## 📌 Nota
Proyecto autónomo de práctica. Mi fuerte profesional son las pruebas manuales (13 años de experiencia). La automatización es una habilidad complementaria que mantengo actualizada.
