# Proyecto de Automatización con Playwright (Java)

Proyecto personal para demostrar habilidades en automatización de pruebas end-to-end (E2E) con el framework **Playwright** usando **Java** y **JUnit**. El objetivo es validar flujos críticos de una aplicación web de práctica.

## 🚀 Tecnologías usadas
- Java 11+
- Maven
- Playwright
- JUnit 5
